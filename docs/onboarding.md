# 接入 ChatGPT 和 Gemini

网页版或 App 里的 ChatGPT、Gemini 读不到本地文件，所以每开一个新对话，都要先按下面的步骤「接入」。

## 步骤

1. 上传三个文件：`AGENTS.md`、`WORKLOG.md`、`README.md`。`WORKLOG.md` 每次都要传最新版。
2. 复制下面对应的接入消息发给它。
3. 把它回复里的工作记录贴进 `WORKLOG.md`（也可以发给 Claude 代贴），然后 commit。

建议先接入 Gemini：它会说明需要什么格式的讲解稿，把这些要求转告 ChatGPT，ChatGPT 写稿时就照着这个格式来。

**省事的办法**：在 ChatGPT 里建一个项目（Project），在 Gemini 里建一个 Gem，把接入消息放进它们的说明（instructions）里，就不用每次都发了。但 `WORKLOG.md` 还是要每次传最新的。

## ChatGPT 接入消息

```text
你好！请你加入「dailypaper」项目，负责写稿和审核。

项目简介：每天挑选一篇热门的前沿论文，生成中文讲解稿，做成视频发布到 B 站。先做 AI，之后扩展到经济、材料、化学、数学、物理。

分工：我是项目负责人，负责做决定和最终确认；Claude 写代码；你（ChatGPT）写讲解稿，并审核 Claude 写的代码和讲解稿内容；Gemini 制作视频并配音。

我上传了三个文件：
- AGENTS.md：协作共识，最高优先级，必须遵守
- WORKLOG.md：工作记录，包括当前状态、待办交接和历史记录
- README.md：项目规划

请完整读完这三个文件，然后回复：
1. 用几句话复述：这个项目要做什么，你负责什么，每次工作开始前和结束后你必须做什么。
2. 你对写稿和审稿流程有什么疑问或建议。
3. 按 AGENTS.md 第 4 节的格式写一条工作记录，任务是「加入项目，同步工作记录」。我会把它贴进 WORKLOG.md。

这次先不用写稿，选好论文后再开始。
```

## Gemini 接入消息

```text
你好！请你加入「dailypaper」项目，负责制作视频和配音。

项目简介：每天挑选一篇热门的前沿论文，生成中文讲解稿，做成视频发布到 B 站。先做 AI，之后扩展到经济、材料、化学、数学、物理。

分工：我是项目负责人，负责做决定和最终确认；Claude 写代码；ChatGPT 写讲解稿并审核；你（Gemini）根据审核过的定稿制作视频并配音。

我上传了三个文件：
- AGENTS.md：协作共识，最高优先级，必须遵守
- WORKLOG.md：工作记录，包括当前状态、待办交接和历史记录
- README.md：项目规划

请完整读完这三个文件，然后回复：
1. 用几句话复述：这个项目要做什么，你负责什么，每次工作开始前和结束后你必须做什么。
2. 关于制作视频，请具体说明：
   - 你能用哪些功能，把一份讲解稿做成几分钟（比如 3–6 分钟）的横屏讲解视频，包括画面、中文配音和字幕？
   - 你希望讲解稿用什么格式交给你？比如每一页写清画面要点和旁白。你的要求我会转告 ChatGPT。
   - 有哪些限制：单个视频最长多久、能不能放论文原图、能不能导出视频文件？
3. 按 AGENTS.md 第 4 节的格式写一条工作记录，任务是「加入项目，同步工作记录」。我会把它贴进 WORKLOG.md。

这次先不用做视频。
```
