# 讲解稿格式 v1.1 提案：开头字段和各版式字段

> **状态：已审核并合并（2026-10-06）**。ChatGPT 已完成 T16，内容已合入 docs/script-format.md 定稿 v1.1，并补充字段必填、分隔符、页码、红框及素材约定。本文保留原提案供追溯，后续写稿以定稿为准。
> 目的：让合成脚本能把稿件内容准确填进模板。v1 里「画面」下的「屏幕文案」「素材」两行，改成按版式分别填写的固定字段；「旁白」「原文核对表」「发音替换表」不变。

## 写法约定

- 每个字段一行：`- 字段名：内容`。
- 一行里有几项内容时，用 ` | ` 分隔。
- 可以有 1~3 条的字段（如「要点」），每条单独写一行，写几条就显示几条。
- 标了「可选」的字段，用不到就省略。

## 开头

```markdown
## 开头

- 视频标题：……
- 简介：……
- 标签：标签1、标签2、标签3
- 领域：AI · 大模型
- 论文标题：（英文原名）
- 作者：……
- 机构：……
- arXiv：2510.01234v2（带版本号）
- 状态：预印本 / 已接收
- 会议或期刊：NeurIPS 2026（预印本写「无」）
- 链接：https://arxiv.org/abs/2510.01234v2
```

## 各版式的「画面」字段

每页的「画面」都从 `- 版式：` 开始，只能填下面 6 个名字之一。页码和总页数由脚本自动计算，页面左上角的主题取自每页标题「第 X 页 · 主题」。

### cover（封面 / 导读）

```markdown
- 版式：cover
- 核心突破：一句话说清这篇论文最重要的贡献
```

论文标题、作者、arXiv 编号等自动取自「开头」。

### figure_text（左图右文）

```markdown
- 版式：figure_text
- 步骤标签：方法（可选，如「背景」「方法」「实验」）
- 主标题：……
- 原图：Figure 2 | 第 3 节 | 图注
- 要点：要点标题 | 一句话说明（1~3 条）
```

### big_metric（全屏大字 / 核心指标）

```markdown
- 版式：big_metric
- 主标题：……
- 数据集：……
- 指标：指标名 | 符号 | 数值 | 单位 | 一句话说明（1~3 条）
- 对比基线：……
- 测试环境：……（没有写「无」）
- 原文出处：Table 2
```

「指标」示例：`推理速度 | ↑ | 2.3 | 倍 | 相同精度下的提速`

### figure_annotated（原图聚焦标注）

```markdown
- 版式：figure_annotated
- 主标题：……
- 聚焦模块：Decoder
- 原图：Figure 2 | 第 3 节
- 标注：红框标签 | 待定
- 要点：要点标题 | 一句话说明（1~3 条）
```

红框位置写稿时先写「待定」，由用户准备材料时看着原图改成 `上, 左, 宽, 高`，都是相对原图的百分比，如 `25%, 45%, 35%, 40%`。

### concept_diagram（概念示意图）

```markdown
- 版式：concept_diagram
- 主标题：……
- 示意图：描述这张图要画什么（由 Gemini 按描述制作）
- 步骤：步骤标题 | 一句话说明（1~3 条）
```

### comparison（方案对比）

```markdown
- 版式：comparison
- 主标题：……
- 基线：基线方案名称
- 本文：本文方案名称
- 基线要点：要点标题 | 一句话说明（1~3 条）
- 本文要点：要点标题 | 一句话说明（1~3 条）
```

## 图片文件约定

- 论文原图：准备材料时存进本期文件夹的 `figures/`，文件名是图号去掉空格和括号、全部小写，如 `Figure 2` → `figure2.png`，`Figure 3(b)` → `figure3b.png`，`Table 1` → `table1.png`。
- 示意图：由 Gemini 制作，存进本期文件夹的 `diagrams/`，按页码命名，如第 5 页 → `page5.png`。

## 字数建议

- 主标题：不超过 20 字
- 要点标题：不超过 12 字；说明：不超过 30 字
